# 角色头像生成提示词

## 通用风格描述（所有角色共用）

把以下通用风格描述加到每个角色的 prompt 前面：

```
SBTI style character portrait card, clean modern digital illustration, bust/headshot composition, 
semi-flat vector art style, clean solid color background with subtle decorative border, 
character wearing Ming dynasty official court attire, confident expression, 
card UI layout format, portrait on the left with personality type label on the right, 
text "你的大明人格类型是：" in modern Chinese typography,
professional character design, crisp lines, balanced composition, commercial illustration quality,
warm studio lighting on face, slightly stylized facial features
```

## 使用说明

1. 去《大明王朝1566》剧照中找每个角色的清晰面部截图
2. 把截图 + 对应的 prompt 一起发给 AI 工具（Midjourney / Stable Diffusion / DALL-E 等）
3. 如果 AI 工具不支持中文字体，可以先生成人物图，再用 Photoshop/Canva 加文本
